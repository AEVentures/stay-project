# In Memory

The Stay Project keeps a quiet, opt-in memorial space for anyone who has
lost someone to suicide and would like to add a name, a photo, or a few
words in their memory. It is entirely voluntary — this file only grows if
people choose to add to it.

## How to add someone

1. Open a pull request editing this file, following the format below, or
2. [Open an issue](https://github.com/AEVentures/stay-project/issues/new)
   and a maintainer will add it with care.

Only submit an entry for someone if you have the right to share it — as a
family member, or with the explicit permission of the person's family.
We will remove an entry at any time upon request from family.

## Suggested format

```markdown
## [First name, or First and Last name]

[Years, if you'd like] — [one or two sentences about who they were]

[Optional: a short memory, tribute, or a cause/organization to support in
their memory]
```

## Editorial guidelines for this page

Per suicide-prevention safe-messaging guidance, entries on this page should:

- Focus on the person's life, personality, and the people who loved them —
  not the circumstances or method of their death.
- Avoid language that suggests suicide was inevitable, simple, or a
  solution.
- Include a path to help (see [docs/RESOURCES.md](./RESOURCES.md)) near any
  personal or emotional content.
